## Bug trouvé et corrigé pendant la recette
Avec le mode hors ligne (service worker) actif, la page qui héberge Java (`runner.html`) était remplacée par
l'accueil de l'appli : **Java ne démarrait pas**. Les tests E2E désactivent le service worker et ne le voyaient pas.
Corrigé, et couvert par un test (« Java s'exécute AVEC le service worker actif »).
